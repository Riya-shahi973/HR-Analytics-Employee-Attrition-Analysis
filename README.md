# HR Analytics – Employee Attrition Analysis

## Project Overview
This project analyzes employee attrition using Python to identify patterns and factors associated with employees leaving an organization.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Exploratory Data Analysis (EDA)

## Dataset
- Total Employees: 1,470
- Total Columns: 35
- Target Variable: Attrition
- Missing Values: 0

## Key Findings
- Overall employee attrition rate is 16.12%.
- Sales department attrition rate is 20.63%.
- Employees working overtime have a higher attrition rate (30.53%) than those not working overtime (10.44%).
- Sales Representatives have the highest attrition rate among the analyzed job roles (39.76%).
- Employees with 0–1 years at the company have an attrition rate of 34.88%.

## Project Workflow
1. Data loading using Pandas
2. Data quality and missing-value checks
3. Exploratory Data Analysis
4. Attrition analysis by department, overtime, job role, and tenure
5. Data visualization using Matplotlib
6. Key findings and HR recommendations

## Conclusion
The analysis identifies employee groups with higher attrition rates. These insights can help HR teams investigate retention challenges and make data-informed decisions.
